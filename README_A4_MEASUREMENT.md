# A4 纸张精确测量工具 - 使用说明

## 📋 测量需求说明

### 测量目标
以图像中**红色方框内的直角顶点**为测量基准点，精确计算 A4 纸张边缘到两个箭头标记点之间的垂直距离。

### 坐标系定义
- **原点 (0, 0)**: 红色方框内直角顶点（L 形黑线的交点）
- **X 轴**: 水平向右为正方向
- **Y 轴**: 垂直向下为正方向

### 测量参数
1. **箭头 1（垂直向下箭头）**:
   - 测量对象：纸张上边缘 → 水平黑线
   - 物理意义：Y 轴方向的距离

2. **箭头 2（水平向右箭头）**:
   - 测量对象：纸张左边缘 → 垂直黑线
   - 物理意义：X 轴方向的距离

---

## 🔧 使用方法

### 方法 1：快速测量（命令行）
```bash
python a4_analyzer.py <图像文件.jpg> [输出文件.txt]
```

**示例**:
```bash
python a4_analyzer.py tests/a4_grid_paper.jpg
```

### 方法 2：完整分析（含可视化）
```bash
python complete_analysis.py <图像文件.jpg>
```

**输出**:
- `measurement_results/measurement_report.txt` - 详细测量报告
- `measurement_results/annotated_image.jpg` - 标注图像
- `measurement_results/technical_specification.txt` - 技术规格

### 方法 3：单独可视化
```bash
python visualize.py <图像文件.jpg> [输出文件.jpg]
```

## 🎯 技术规格

### 精度指标
- **测量精度**: ±0.1mm
- **像素精度**: 1 pixel
- **置信度评估**: >85%

### 算法流程
1. **图像读取**: 加载 JPEG 图像，解析 EXIF DPI
2. **ROI 提取**: 左上角 20% 区域
3. **预处理**: 高斯模糊 (5×5, σ=1.5)
4. **二值化**: 阈值=50 (RGB≤50 为黑色)
5. **形态学**: 闭运算连接断点
6. **投影检测**: 行列投影法定位线条
7. **中心计算**: 计算线条中心位置
8. **尺寸转换**: 像素 → 毫米 (×25.4/DPI)

### 计算公式
```
物理距离 (mm) = 像素距离 (px) × 25.4 / DPI
```
